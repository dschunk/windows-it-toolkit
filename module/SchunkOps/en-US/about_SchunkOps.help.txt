SHORT DESCRIPTION
    Practical IT operations diagnostics from help desk triage through senior infrastructure engineering by David Schunk.

LONG DESCRIPTION
    SchunkOps is the installable PowerShell module from the Windows IT Toolkit.
    Version 1.4 provides forty-four object-first commands spanning endpoint triage,
    Windows Server health, DNS and network diagnostics, domain trust, Active Directory
    replication and privileged groups, account lockouts, Kerberos, Group Policy,
    DHCP/DNS, certificates, firewall posture, RDP/NLA, DFS Namespace, IIS health and
    logs, Hyper-V, SQL Server, Windows Server Backup, failover clustering, fleet CIM
    health, VMware vSphere, local administrators, TLS, events, software, updates,
    scheduled tasks, listening ports, pending reboots, BitLocker, authentication,
    and service failures.

    SchunkOps can also create integrity-hashed incident bundles and compare evidence
    captures before and after remediation.

    The commands use safe, read-only defaults and return structured objects so they
    can be filtered, exported, scheduled, attached to tickets, and integrated into
    operations workflows.

GETTING STARTED
    Install-Module SchunkOps -Scope CurrentUser
    Import-Module SchunkOps
    Get-Command -Module SchunkOps
    Get-Help Get-SchunkEndpointTriage -Full
    Get-Help Get-SchunkAccountLockoutTrace -Full
    Get-Help Get-SchunkKerberosSpnAudit -Full
    Get-Help Get-SchunkFleetHealth -Full
    Get-Help New-SchunkIncidentBundle -Full

WINDOWS SERVER OPERATIONS
    SchunkOps 1.3 adds a coordinated Windows Server audit and focused read-only
    diagnostics for IIS, Hyper-V, SMB/NTFS permissions, Group Policy application,
    Windows DNS Server, Windows DHCP Server, and Windows Update health.

    Example:
        Invoke-SchunkServerAudit -IncludeIis -IncludeHyperV -HtmlPath C:\Reports\server-audit.html


DAY-TWO OPERATIONS
    SchunkOps 1.4 adds read-only diagnostics for firewall posture, Remote Desktop,
    DFS Namespace, certificate inventory, privileged Active Directory groups,
    IIS W3C logs, local SQL Server services/listeners, and Windows Server Backup.

    Example:
        Get-SchunkFirewallAudit -IncludeRules
        Get-SchunkCertificateInventory -WarningDays 45
        Get-SchunkPrivilegedGroupAudit
        Get-SchunkSqlServerHealth
