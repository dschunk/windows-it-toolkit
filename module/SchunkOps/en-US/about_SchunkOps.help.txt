SHORT DESCRIPTION
    Practical IT operations diagnostics from help desk triage through senior infrastructure engineering by David Schunk.

LONG DESCRIPTION
    SchunkOps is the installable PowerShell module from the Windows IT Toolkit.
    Version 1.2 provides twenty-eight object-first commands for endpoint triage,
    Windows server health, DNS and network diagnostics, domain trust, Active Directory
    replication, account lockout tracing, Kerberos SPN analysis, Group Policy change
    review, DHCP/DNS consistency, certificate-chain validation, failover-cluster health,
    fleet CIM health, VMware vSphere inventory, local administrator review, TLS, events,
    software, updates, scheduled tasks, listening ports, pending reboots, BitLocker,
    authentication, and service failures.

    SchunkOps can also create integrity-hashed incident bundles and compare evidence
    captures before and after remediation.

    The commands use safe, read-only defaults and return structured objects so they
    can be filtered, exported, scheduled, attached to tickets, and integrated into
    operations workflows.

GETTING STARTED
    Install-Module SchunkOps -Scope CurrentUser
    Import-Module SchunkOps
    Get-Command -Module SchunkOps
    Get-Help Get-SchunkEndpointTriage -Full
    Get-Help Get-SchunkAccountLockoutTrace -Full
    Get-Help Get-SchunkKerberosSpnAudit -Full
    Get-Help Get-SchunkFleetHealth -Full
    Get-Help New-SchunkIncidentBundle -Full
