# Support

This is a community open-source project, not a commercial support agreement.

## Get help

1. Read the script's parameters and repository documentation.
2. Confirm module, privilege, and platform requirements in [docs/PRIVILEGES.md](docs/PRIVILEGES.md).
3. Search existing GitHub issues.
4. Open a sanitized issue with expected behavior, actual behavior, PowerShell version, Windows version, and reproducible steps.

Never attach credentials, tokens, recovery keys, internal addresses, directory exports, event logs containing personal data, or proprietary configuration.

For professional writing and project updates, follow [Best Practices for Everyday IT](https://www.linkedin.com/newsletters/best-practices-for-everyday-it-7075059974573314048/).
