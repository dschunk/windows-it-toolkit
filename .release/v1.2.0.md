# SchunkOps 1.2.0 release trigger

This branch exists solely to trigger the protected SchunkOps release pipeline for version 1.2.0.

Expected outcomes:

- validate manifest version 1.2.0
- run Pester and PSScriptAnalyzer release gates
- Authenticode-sign module files
- build SchunkOps-1.2.0.zip
- generate a SHA-256 checksum
- publish SchunkOps 1.2.0 to PowerShell Gallery
- verify Gallery publication
- create GitHub release v1.2.0 with signed artifact and checksum
