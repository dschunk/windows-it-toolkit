# Using and crediting this toolkit

The Windows IT Toolkit is released under the MIT License. You may use, copy, modify, and distribute it, including inside commercial environments, provided the copyright and license notice are preserved in copies or substantial portions.

## Preferred attribution

When sharing a script, adaptation, article, training resource, or internal toolkit derived from this project, use:

> Based on the Windows IT Toolkit by David Schunk — https://github.com/dschunk/windows-it-toolkit

## Why attribution matters

Credit helps administrators find the maintained source, security updates, documentation, and future releases. It also helps sustain the public work required to test and improve reusable operational tooling.

Do not add tracking, telemetry, or external network calls in order to enforce attribution. Trust and transparent source code matter more than surveillance.
