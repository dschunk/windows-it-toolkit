# Security Policy

## Public examples

This repository is designed for reusable, sanitized examples. Do not submit credentials, keys, tokens, webhook URLs, private addresses, internal hostnames, personal data, or proprietary configuration.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Contact the maintainer through the private contact options linked from [davidschunk.com](https://www.davidschunk.com/) with:

- affected file and version or commit
- impact and prerequisites
- reproduction steps using sanitized data
- suggested mitigation, if known

Reports will be evaluated before technical details are disclosed publicly.

## Operational responsibility

Examples must be reviewed and tested before use. Operators remain responsible for access control, backups, change approval, monitoring, logging, recovery, and compliance in their own environments.
